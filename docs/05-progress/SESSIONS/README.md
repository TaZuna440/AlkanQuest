# Session Logs

Optional one-file-per-session detailed logs.

Use when:
- A session involved complex decisions
- A session spanned multiple days
- A session needs detailed replay

Naming: YYYY-MM-DD_session-N.md

## Template

# Session - YYYY-MM-DD

Phase: XX - Name
Duration: ~X hours

## Goal
What we intended to accomplish.

## Done
- [x] Task 1

## Not Done
- [ ] Task 2 (reason)

## Decisions Made
- Decision X because Y

## Next Session
- Task 3
