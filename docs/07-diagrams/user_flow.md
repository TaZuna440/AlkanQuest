# Primary User Journeys

## Journey 1 — First Session

Open app
↓
Splash
↓
System Awakening
↓
Hunter Registration (enter name)
↓
First Quest Assignment (pick template or skip)
↓
System Briefing (if quest created)
↓
Home



## Journey 2 — Daily Check-in

Open app
↓
Home → "I SAVED IT"
↓
Check-in form
↓
Enter amount + optional note/proof
↓
Confirm
↓
Success message → Home (updated)

## Journey 3 — Complete a Challenge

Check-in pushes total ≥ target
↓
Full-screen celebration
↓
Achievement cards (if any unlocked)
↓
Home with "Create new challenge?" prompt
↓
Completed challenge moves to Cleared tab

## Journey 4 — Cancel a Challenge

Challenge Detail → Cancel
↓
Confirmation dialog
↓
Challenge status → Cancelled
↓
Records preserved
↓
Streak resets to 0
↓
Challenge moves to Cancelled tab
