# Primary User Journeys

## Journey 1 - First Session

Open app -> Splash -> System Awakening -> Hunter Registration -> First Quest Assignment -> System Briefing -> Home

## Journey 2 - Daily Check-in

Open app -> Home I SAVED IT -> Check-in form -> Enter amount -> Confirm -> Success -> Home (updated)

## Journey 3 - Complete a Challenge

Check-in pushes total >= target -> Full-screen celebration -> Achievement cards -> Home with new challenge prompt -> Completed challenge to Cleared tab

## Journey 4 - Cancel a Challenge

Challenge Detail -> Cancel -> Confirmation dialog -> Status Cancelled -> Records preserved -> Streak resets to 0 -> Cancelled tab
