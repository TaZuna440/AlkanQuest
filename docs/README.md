---

## Two-Phase Approach

This documentation separates **planning** from **execution**:

### 04-development (The Plan)
- What we will build
- 12 phases, each with scope, deliverables, acceptance criteria
- Updated rarely — changes when the plan itself changes

### 05-progress (The Tracking)
- What we have actually done
- Changelog with dated entries
- Current phase + blockers + next steps
- Updated constantly — every working session

**Rule:** Development folder = future. Progress folder = present + past.
