# MVP Roadmap

12 phases. ~12 weeks. Focus: validate the core loop.

## Phase Overview

| # | Phase | Duration | Deliverable |
|---|-------|----------|-------------|
| 01 | Foundation | 1 week | Flutter project + theme + router |
| 02 | Core Models | 1 week | Drift schema + repositories |
| 03 | Onboarding | 1 week | 5-screen flow working |
| 04 | Create Challenge | 1 week | Form + validation + pickers |
| 05 | Check-in | 1 week | Form + draft + proof |
| 06 | Home Dashboard | 1 week | Status Window with live data |
| 07 | Challenge Detail | 1 week | Progress + history + edit |
| 08 | Status (Progress) | 1 week | Stats + rank + XP |
| 09 | Achievements | 3 days | Unlock logic + celebration |
| 10 | Notifications | 4 days | Permission + daily reminder |
| 11 | Profile & Settings | 4 days | Profile + settings + about |
| 12 | Polish | 2 weeks | Animations + tests + edges |

**Total:** ~12 weeks

## Milestone Tags

After each phase:
- `v0.1.0-phase-01` through `v0.12.0-phase-12`
- `v1.0.0-mvp` — after Phase 12 complete + tested
