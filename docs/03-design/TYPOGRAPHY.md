# Typography

## Font Stack

| Family | Source | Weights | Use |
|--------|--------|---------|-----|
| **Orbitron** | Google Fonts | 400, 700, 800 | Window titles, big numbers |
| **Rajdhani** | Google Fonts | 400, 500, 600, 700 | Headers, labels, body |
| **JetBrains Mono** | Google Fonts | 400, 700 | Values, amounts, timestamps |

## Scales

| Use | Family | Weight | Size | Style |
|-----|--------|--------|------|-------|
| Window Title | Orbitron | 700 | 20–24 | ALL CAPS, letter-spacing 0.15em |
| Section Header | Rajdhani | 600 | 14–16 | ALL CAPS, letter-spacing 0.10em |
| Label | Rajdhani | 500 | 12–13 | ALL CAPS |
| Big Number | Orbitron | 800 | 40–72 | White, magenta glow |
| Value | JetBrains Mono | 500 | 14–32 | |
| Body | Rajdhani | 400 | 14–16 | Sentence case |
| Bonus Value | JetBrains Mono | 700 | 12–14 | Green `#39FF88` |

## Rules

- ALL CAPS for system messages and labels
- Sentence case for body text and descriptions
- Numbers always monospace (JetBrains Mono)
- Letter-spacing on ALL CAPS: 0.10–0.15em
