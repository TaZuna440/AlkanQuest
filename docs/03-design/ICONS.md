## Icon Spec

- Canvas: 32×32 and 48×48
- Stroke: 1.5px
- Line cap: round
- Line join: round
- Frame: hexagonal, cyan/magenta glow when selected
- Default color: lavender `#E0D4F5`

## Selection State

- Border: `#B026FF` 2px
- Glow: `0 0 12px rgba(176, 38, 255, 0.6)`
- Icon fill: `#FFFFFF`
