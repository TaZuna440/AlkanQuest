# Project Overview

## What Is This?

**AlkanQuest** — a gamified savings app for Filipino users. Turns saving money into quests. Inspired by Solo Leveling's System Window.

## Core Concept

Users create savings challenges ("quests"), log their savings ("check-ins"), earn XP, level up through ranks E→S, and build streaks by completing challenges in a row.

## What It Is NOT

- Not a bank
- Not a wallet
- Not an investment platform
- Not a verification system

## Target Market

Filipino users (primary), soft launch in Philippines → global.

## Theme

Solo Leveling / Shadow System Window — neon magenta, dark void, holographic panels.

## Success Metric

> Do users repeatedly come back and save?

**Primary metrics:**
- D7 retention ≥ 25%
- Challenges per user ≥ 1.5
- Check-ins per week ≥ 3
